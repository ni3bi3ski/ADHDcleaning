# ADHDcleaning

Grywalizowana aplikacja do sprzątania i codziennych nawyków (SwiftUI, iOS/macOS) z zadaniami, XP, złotem, HP, osiągnięciami, sklepem, zwierzakami i wyzwaniami tygodniowymi.

## Prywatność

Aplikacja działa w pełni lokalnie. Nie ma kont, serwera, analityki ani wysyłania danych. Stan gry jest zapisany na urządzeniu (UserDefaults) wraz z kopią JSON w Application Support.

## Budowanie

1. Otwórz `aplikacjadonauki/aplikacjadonauki.xcodeproj` w Xcode.
2. W Signing & Capabilities wybierz własny Team i zmień Bundle Identifier na własny.
3. Uruchom na symulatorze lub urządzeniu.
